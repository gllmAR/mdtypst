# A Minimal Article Template

*Casey Example — 2026-01-10*

## Abstract

This article demonstrates an academic-style layout using a Typst sidecar. The Markdown provides structure and content; the sidecar provides typography.

## Introduction

Markdown is great for writing. Typst is great for layout. A sidecar template connects the two.

### Contributions

- Clear separation of content and presentation
- Deterministic PDF output
- Works well with static hosting

## Methods

We define a simple set of show rules for headings, spacing, and a title block.

## Results

The resulting PDF is readable and consistent.
