# CS101 — Introduction to Computing

*Syllabus · Dr. Ada Example · Spring 2026*

## Course overview

CS101 introduces foundational ideas in programming and computer systems.

## Learning outcomes

By the end of this course, you should be able to:

- Write small programs using variables, conditionals, loops, and functions.
- Read and modify existing code using basic debugging techniques.
- Explain core concepts (data representation, algorithms, complexity).
- Use version control to collaborate on small assignments.

## Assessment
