# Typst Templates (Targets)

This folder contains **mdtypst adaptations** inspired by the official Typst templates repo:

- https://github.com/typst/templates

We **do not vendor or copy** upstream template sources here.

Instead, each target has:

- `README.md` — the content (Markdown)
- `README.mdtypst.typ` — the formatting (Typst sidecar template)

The goal is to validate that mdtypst can support the kinds of layouts users expect from curated Typst templates, while keeping authoring in Markdown.

## Targets

- `appreciated-letter/` — letter layout
- `charged-ieee/` — compact technical article layout
- `wonderous-book/` — small book layout
- `dashing-dept-news/` — newsletter layout

Tip: open `render.html` and use the **Examples** panel to browse `examples/typst-templates/...`.
